01 Multi-agent workflow · bank marketing

Campaign Copilot

The problem
A bank marketer wants a campaign that is backed by data and clears compliance. Today that is a week of handoffs between marketing, analytics and compliance, and afterwards nobody can show why a claim was allowed.
What I built
Five LangGraph agents. The planner breaks the goal down. The audience agent queries a synthetic bank dataset only through an MCP server. The copy agent drafts a letter, an email and two ads and cites the data behind each choice. The compliance agent runs a deterministic rulebook with retrieval over policy text and cites the paragraph for every flag. The evaluator scores and loops back at most twice. Then the graph stops for a human to approve. Every step lands in a hash-chained audit log.

02 Research · tamper-evident agent memory

Overseer

The problem
When AI agents share a memory, one wrong or malicious write silently poisons every later decision, and nobody can prove what an agent knew at the moment it acted.
What I built
A paper and reference implementation of tamper-evident memory for agents: a bitemporal knowledge graph that records both when a fact was true and when it was written, with append-only, hash-chained events and external anchoring. Corrections are new records, never edits, so "what did the agent believe at 10:05?" has an exact answer. Verified with property tests, an adversarial battery and formal checks.

02 · How I build

Four rules I apply to every agent system.

01

Data through tools, not prompts

Agents reach data only through typed, logged tools (MCP). No raw SQL in a prompt, no number that cannot be traced to a call.

02

Rules first, model second

Whether copy says "guaranteed" is not a judgement call. Deterministic rules decide; retrieval cites the policy; the model proposes the rewrite.

03

Evals before features

A golden set with a CI threshold. Writing Campaign Copilot's 20 goals found four real bugs before any user did.

04

A human in the loop by construction

The approval gate is a graph interrupt with a checkpointer, so nothing ships without a decision, and the decision is in the audit log.
