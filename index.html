Multi-agent workflow · Banking marketing

Campaign Copilot

The problem
A bank marketer wants a campaign that is backed by data and clears compliance. Today that is a week of handoffs between marketing, analytics, and compliance, and nobody can show afterwards why a claim was allowed.
What I built
A LangGraph workflow of five agents. The planner breaks the goal down; the audience agent queries a synthetic bank dataset only through an MCP server; the copy agent drafts a letter, an email, and two ads and cites the data behind each choice; the compliance agent runs a deterministic rulebook with retrieval over policy text and cites the paragraph for every flag; the evaluator scores and loops back at most twice. The graph then stops for a human to approve. Every step lands in a hash-chained audit log.
Stack
Python 3.11LangGraphMCP SDK 2Claude structured outputsFastAPI + SSEReact · TypeScript · Vitepytest · 20 golden evals · CI

Northwind Community Bank is fictional and the data is synthetic. The demo replays a recorded run; clone the repo to run the live agents with no API key.

Research · Tamper-evident agent memory

Overseer

The problem
When AI agents share a memory, one wrong or malicious write silently poisons every later decision, and nobody can prove what an agent knew at the moment it acted.
What I built
A paper and reference implementation of tamper-evident memory for AI agents: a bitemporal knowledge graph that records both when a fact was true and when it was written, with append-only, hash-chained events and external anchoring. Corrections are new records, never edits, so "what did the agent believe at 10:05?" has an exact answer. Verified with property tests, an adversarial battery, and formal checks.
Stack
PythonNumPy · SciPyHypothesis property testsZ3SHA-256 chaining

The demo lets you edit a record in a six-event agent ledger and watch verification fail at that line. It runs entirely in your browser.

3D simulation · Training

AeroMind FlightLab

The problem
New drone operators crash real hardware while they are still learning what pitch, roll, yaw, and throttle do, and what the telemetry is telling them.
What I built
A browser-based 3D flight simulator that teaches stick inputs, telemetry literacy, and failsafe behavior before a first real flight. Every input becomes a visible, explained physics lesson, with scored scenarios and a readable HUD.
